# Simulink Models for LKA

All models in this folder are **generated** by `scripts/build_lka_models.m`.
After changing that script, or the MPC/vehicle parameters it bakes in, rebuild them:

```matlab
run('config/startup.m'); build_lka_models();
```

The algorithm code lives in `src/` and is called from MATLAB Function blocks.
The same files are unit-tested in `tests/unit_tests/test_lka_core.m`.

## 2. `VirtualLaneSensor.slx` (subsystem reference)

This is an emulated camera lane detector. From the true lane geometry it produces
what a detector would report:
- frame sampling at 20 Hz;
- Gaussian noise on offset, heading, curvature and curvature rate;
- random per-frame misses;
- scenario-forced outages;
- processing latency (a Delay block).

A real detector, for example a MATLAB port of the Asterix sliding-window detector,
can replace it as long as it fills `LaneSensorBus`.

## 3. `LKA_MIL_TestBench.slx` (fixed-step ode4, 5 ms)

```
Scenario ─► Driver Speed Tracking ─────────────┐
Steering Actuator (60°/s, ±32°, 0.1 s lag) ─► Vehicle Dynamics (Baja single-track) ─► Lane Geometry (xodr)
       ▲                                                   │                              │
       └──────── LKA Controller (model ref) ◄── Virtual Lane Sensor ◄─────────────────────┘
                                                Ground Truth Metrics (tyre-to-line margins)
```

It reads the base-workspace variables `LKA`, `vehicle`, `SCN` (scenario
parameters) and `ROAD` (lane arrays). `scripts/run_lka_mil.m` sets these up.

## `LKA_Vision_TestBench.slx` (camera-in-the-loop, Unreal)

Generated by `scripts/build_lka_vision_bench.m` from `LKA_MIL_TestBench.slx`:
- **Emulated sensor replaced** by the camera chain: rear-axle pose → Simulation 3D Vehicle with Ground
  Following (official LKA track, `data/scenes/LKA/LKA.usd`, no RoadRunner needed) → Simulation 3D Camera
  → `Vision Lane Detector` (MATLAB System `LkaVisionLaneDetector`) → one frame of latency → `LKA_Controller`.
- **Ego Sensors** (wheel speed + gyro model) in front of the controller's speed and yaw-rate inputs.
- **Vision Recorder** writes the annotated video when `LKA.Vision.Bench.VideoFile` is set.
- **Frame Logger (dev only)** writes benchmark datasets when `LKA.Vision.Bench.DatasetDir` is set.
- **Ground truth** (road geometry) feeds only the metrics and the frame logger.

The scene path is stored as an absolute path, so rebuild the bench after moving the repository:
`build_lka_vision_bench()`. Run it with `run_lka_vision(...)`, after `calibrate_vision_bench()` on a new PC.
